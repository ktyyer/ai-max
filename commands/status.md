# /aimax:status — 状态查看

> **查看项目当前状态、Self-* 学习情况和建议**

## 🆕 v3.0 增强

集成 Self-* 系统，显示：
- 🧠 Self-Aware：已学习的编码模式和置信度
- 📈 Self-Improving：反馈统计和改进建议
- 🤖 自我进化进度：从新手到完全掌握

---

## 显示内容

### 项目概览
- 项目名称和路径
- 语言和框架
- 文件统计

### Self-* 系统状态
- **Self-Aware**：已学习的模式列表
- **Self-Improving**：反馈统计、改进建议
- **Self-Fixing**：自动修复记录
- **Self-Building**：自动初始化状态

### 三大记忆系统
- Project Memory：会话、决策、FAQ
- Smart Context：索引状态、搜索能力
- Conversational State：活跃会话、检查点

### 已学习的模式
- 编码模式列表
- 置信度评分（0.3 → 0.6 → 0.8 → 0.95）
- 使用次数
- 学习阶段（候选 → 学习中 → 已确认 → 完全掌握）

### 最近活动
- 最近任务
- 最近决策
- 最近学习

### 建议操作
- 待优化项
- 技术债务
- 改进建议

## 示例

```bash
/aimax:status
```
