# /aimax:status — 状态查看

> **查看项目当前状态、记忆和建议**

## 显示内容

### 项目概览
- 项目名称和路径
- 语言和框架
- 文件统计

### 记忆系统状态
- 项目记忆条目数
- 对话记忆条目数
- 团队知识条目数

### 已学习的模式
- 编码模式列表
- 置信度评分
- 使用次数

### 最近活动
- 最近任务
- 最近决策
- 最近学习

### 建议操作
- 待优化项
- 技术债务
- 改进建议

## 示例

```bash
/aimax:status
```
